Решение: сохранить HTML, CSS и JavaScript без сборки и внешних ресурсов.
Почему: утилита работает локально, существующий API покрывает весь интерфейс.
Не менять без: согласования новых зависимостей.

# Stealth по сравнительному файлу

Решение: заменить старый Stealth способом с единственной раздутой аудиодорожкой и наблюдаемыми параметрами after-others-patch.mp4. Max сохраняет прежний алгоритм.
Почему: пользователь подтвердил успешную публикацию образца и прямо согласовал воспроизведение этого способа. Сравнение и ограничения записаны в project-state.md.
Не менять без: проверки структуры, тестов реальных потоков и отдельной оценки результата публикации.

# Эксперимент с Telegram Stories

Решение: отдельный плагин exteraGram переключает конвертер на копирование потоков только для подготовленного H.264/AAC 720x1280 с именем storycopy_*.mp4, размером до 30 МБ и без монтажа. Профили оптимизатора не меняются.
Почему: штатный Android-клиент конвертирует видео из галереи. Отключение needConvert целиком ведет в ветку перемещения исходника. Копирование потоков внутри штатного конвертера сохраняет его жизненный цикл и исходный файл. Узкое разрешение исключает рассогласование размеров с метаданными публикации.
Не менять без: проверки нового пути по исходникам, тестов изоляции обычных отправок и проверки на телефоне. Серверное сохранение качества пока не подтверждено.
