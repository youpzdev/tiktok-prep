# Интерфейс без новых зависимостей

Решение: сохранить HTML, CSS и JavaScript без сборки и внешних ресурсов.
Почему: утилита работает локально, существующий API покрывает весь интерфейс.
Не менять без: согласования новых зависимостей.

# Оформление

Не менять без: согласования другого визуального направления.

# Stealth по сравнительному файлу

Решение: заменить старый Stealth способом с единственной раздутой аудиодорожкой и наблюдаемыми параметрами after-others-patch.mp4. Прежнее сохранение алгоритма Max отменено решением ниже.
Почему: пользователь подтвердил успешную публикацию образца и прямо согласовал воспроизведение этого способа. Сравнение и ограничения записаны в project-state.md.
Не менять без: проверки структуры, тестов реальных потоков и отдельной оценки результата публикации.

# Эксперимент с Telegram Stories

Решение: отдельный плагин exteraGram переключает конвертер на копирование потоков только для подготовленного H.264/AAC 720x1280 с именем storycopy_*.mp4, размером до 30 МБ и без монтажа. Профили оптимизатора не меняются.
Почему: штатный Android-клиент конвертирует видео из галереи. Отключение needConvert целиком ведет в ветку перемещения исходника. Копирование потоков внутри штатного конвертера сохраняет его жизненный цикл и исходный файл. Узкое разрешение исключает рассогласование размеров с метаданными публикации.
Не менять без: проверки нового пути по исходникам, тестов изоляции обычных отправок и проверки на телефоне. Серверное сохранение качества пока не подтверждено.

# Max как усиленный Stealth

Решение от 17.10.2026: обязательное перекодирование Main L5.2, slow/CRF14,
пределы по умолчанию 1080/1920/60. Контейнерный метод и единственная
аудиодорожка с фиктивными сэмплами совпадают со Stealth.
Почему: пользователь выбрал Max как усиленный Stealth под TikTok, а не
режим сохранения исходного видеопотока. Старый Max с клоном дорожки заменён.
Не менять без: тестов реального кодирования, сохранности потоков и синхронизации.
Качество после публикации проверяется отдельно от локальной структуры.

# Компактная панель и типографика

Решение от 18.10.2026: компоновка A с одной рабочей панелью, RIBBON,
Unbounded для заголовков, Manrope для текста. Технические сведения
и ghost перенесены в диалог; основная кнопка объединяет выбор и запуск.
Почему: пользователь выбрал эти варианты после сравнения снимков и попросил
убрать лишнее из рабочей зоны. Открытая лицензия Anthropic Sans не найдена,
поэтому в показанном и выбранном варианте используется Manrope с OFL.
Прежняя техническая колонка и fixed dock заменены этим решением.
