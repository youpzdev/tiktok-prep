# TikTok Prep v3.0.0

Max теперь сохраняет до 4K и 120 FPS. Автор проверил публикацию в TikTok
18 октября 2026 года и подтвердил оба параметра после загрузки. Результат
может отличаться на других роликах и аккаунтах.

## Что изменилось

- Max: до 2160 по короткой стороне, 3840 по длинной и 120 FPS. Обязательное
  перекодирование H.264 Main L6.0, slow, CRF14. Исходники ниже этих пределов
  не увеличиваются. Stealth остаётся режимом до 1080p60.
- Фиктивные аудиосэмплы добавляются в одну аудиодорожку. Настоящий звук
  сохраняется; отдельного клона дорожки, как в старой версии, больше нет.
- Полностью новый сайт со встроенной локальной обработкой: компактная
  рабочая панель, очередь, настройки, прогресс, отмена и открытие результата.
- Логотип RIBBON, локальные Unbounded и Manrope, анимация фона и отклик
  элементов. Движение отключается при соответствующей системной настройке.
- RU/EN, сохранение настроек и восстановление задачи после перезагрузки.
  Повтор запроса запуска не создаёт вторую обработку в том же сервере.
- Исправлен поиск Python при запуске через start.bat.

## Запуск

Нужны Python 3 и ffmpeg. Python-пакеты устанавливать не требуется.

1. Установи ffmpeg: `winget install Gyan.FFmpeg`.
2. Распакуй `tiktok-prep-tool-v3.0.0.zip` в отдельную папку.
3. Закрой прежний сервер, если он запущен, и открой новый `start.bat`.
4. В браузере добавь видео, выбери Stealth или Max и запусти обработку.

Обработка идёт на твоём компьютере. ffmpeg и Python в архив не входят.
Шрифты и их лицензии включены, интернет для интерфейса не нужен.

## Проверка

64 Python-теста прошли. Локально проверены реальное кодирование 4K/120,
кадры, синхронизация и сохранность настоящих пакетов после контейнерного
патча. Интерфейс проверен в 1440x900 и 390x844: очередь, оба режима, ошибки,
отмена и RU/EN.

Фиктивный AAC-хвост может мешать совместимости с обычными плеерами.
Контейнерный патч держит файл в памяти, поэтому большим исходникам нужен
запас RAM. Успешная публикация автора не гарантирует тот же результат
каждой следующей загрузки.
