# Обновление интерфейса

Цель: перенести согласованный графитовый макет с лаймовым акцентом в рабочую утилиту.

Границы: static/index.html, static/style.css, static/app.js. Обработка видео, API и формат выходных файлов сохраняются. Диагностика Stealth продолжается отдельно после получения сравнительного файла.

Критерии готовности:
- Очередь слева, настройки справа, основная кнопка в нижней панели.
- На телефоне блоки идут одной колонкой, запуск доступен без горизонтального скролла.
- Выбор файлов и папки, перетаскивание, режимы, язык, запуск, отмена и результат сохраняют поведение.
- Проверены пустая очередь, длинные имена, обработка, ошибка и результат.
- Снимки 1440x900 и 390x844 просмотрены, ошибки браузера проверены.
- Проверка текста проходит, изменения просмотрены и закоммичены локально.
