# Обновление Stealth

Цель: воспроизвести наблюдаемый способ обработки after-others-patch.mp4 и подготовить файл для проверки публикацией. Пользователь согласовал замену алгоритма Stealth.

Границы: профиль ffmpeg в app.py, обработка контейнера в mp4mask.py, тесты и описание актуального поведения. Max сохраняет прежнюю обработку. Исходные пользовательские видео не перезаписываются. Новые зависимости не нужны.

Критерии локальной готовности:
- До исправления тесты показывают отличие старого Stealth от новой спецификации.
- Stealth кодирует H.264 Main L5.2, сохраняет btrt, добавляет наблюдаемое SEI у ключевых кадров.
- При включённой фиктивной дорожке остаётся один аудиотрек, его число сэмплов увеличивается в 10 раз, mdhd сохраняет реальную длительность, edts удалены, mvhd версии 1 обозначает неизвестную длительность.
- Переключатель фиктивной дорожки отключает добавление фиктивных сэмплов. Отсутствующий звук не создаётся искусственно.
- Видеопоток декодируется без ошибок. Реальные AAC-сэмплы не меняются при патче. Ошибки на фиктивном хвосте явно отделены от повреждения реальных данных.
- Тесты проверяют таблицы сэмплов, границы чанков, смещения, атомарную запись и сохранение Max.
- Итоговый файл из before-others-patch.mp4 сравнивается с образцом и сохраняется отдельно.
- Проверка интерфейса после правки текста, ai-check, review и локальный коммит выполнены.

Качество публикации остаётся непроверенным до загрузки пользователем. Неизвестные настройки кодировщика и отличие версии ffmpeg не выдаются за точную копию реализации конкурента.
