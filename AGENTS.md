# Работа с проектом

Сначала читать docs/project-state.md, затем docs/SPEC.md и документы по текущей задаче.

Приложение запускается через start.bat или py -3 app.py. Зависимости Python не требуются, для обработки нужен ffmpeg. Новые зависимости без согласования не добавлять.

Не менять файлы incoming/, tiktok_ready/, release/ и пользовательские видео при работе над интерфейсом. Не менять обработку MP4 в рамках визуальных задач. Не обещать результат загрузки в TikTok по локальной проверке файла.

Исходники интерфейса находятся в static/. Система токенов описана в docs/design/design-main.md. Проверять в браузере 1440x900 и 390x844, смотреть снимки в shots/. Проверять очередь, режимы, RU/EN, ошибки, обработку и отмену. Проверка синтаксиса: node --check static/app.js. Проверка текста: PYTHONUTF8=1 py -3 ~/.codex/tools/ai-check.py .

Каждому агенту отдельная область файлов и отдельный worktree. Агенты не коммитят. Основной агент читает diff, выполняет итоговую проверку и коммитит. Пуш только по явной просьбе.
